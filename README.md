## 🛠️ Tech Stack & Architecture

- **Structure:** Semantic HTML5 with accessibility attributes (`aria-expanded`, `aria-label`, `aria-hidden`)
- **Styling:** Vanilla CSS3 (Custom Design Tokens, Flexbox, CSS Grid, CSS Glassmorphism, Micro-interactions)
- **Logic:** Vanilla JavaScript (ES6+ modular classes, Filter state management, Dynamic DOM modals)
- **Server:** Node.js HTTP server for local serving and static file caching

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/25bit026-afk/portfolio.git
   cd portfolio
   ```

2. **Run with Node.js built-in server:**
   ```bash
   node server.js
   ```

3. **Open in your browser:**
   ```
   http://localhost:8080
   ```
   *(Or navigate directly to `portfolio/index.html` in any modern web browser)*
